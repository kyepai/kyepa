# Shortcut Keys to Memorize First

A starter set for a beginner programmer. Don't try to learn all of these at once —
spend a week on each section before moving to the next.

## Week 1: VS Code (or your editor)

| Shortcut | Action |
|---|---|
| `Ctrl+S` | Save file |
| `Ctrl+Z` / `Ctrl+Shift+Z` | Undo / Redo |
| `Ctrl+C` / `Ctrl+V` / `Ctrl+X` | Copy / Paste / Cut |
| `Ctrl+F` | Find in file |
| `Ctrl+Shift+F` | Find across whole project |
| `Ctrl+/` | Toggle comment on a line |
| `Ctrl+D` | Select next occurrence of current word (multi-cursor) |
| `Ctrl+P` | Quick open a file by name |
| `` Ctrl+` `` | Toggle built-in terminal |

## Week 2: Navigating & editing faster

| Shortcut | Action |
|---|---|
| `Ctrl+Left` / `Ctrl+Right` | Jump one word at a time |
| `Home` / `End` | Jump to start / end of line |
| `Ctrl+Home` / `Ctrl+End` | Jump to start / end of file |
| `Shift+Arrow` | Select text |
| `Ctrl+Shift+K` | Delete the whole line |
| `Alt+Up` / `Alt+Down` | Move current line up / down |
| `Ctrl+G` | Jump to a specific line number |

## Week 3: Terminal basics

| Shortcut | Action |
|---|---|
| `Ctrl+C` | Cancel/kill the running command |
| `Ctrl+L` | Clear the terminal screen |
| `Tab` | Auto-complete file/command names |
| `Up Arrow` | Cycle through previous commands |
| `Ctrl+R` | Search command history |
| `Ctrl+A` / `Ctrl+E` | Jump to start / end of the line you're typing |

## Week 4: General OS (useful everywhere)

| Shortcut | Action |
|---|---|
| `Alt+Tab` | Switch between open windows |
| `Ctrl+Tab` | Switch between tabs in an app |
| `Ctrl+W` | Close current tab |
| `Ctrl+T` | New tab (browser) |

## Week 5: Ubuntu (Linux desktop)

| Shortcut | Action |
|---|---|
| `Super` (Windows key) | Open Activities overview / search apps |
| `Super+A` | Show all applications |
| `Super+D` | Show desktop |
| `Super+L` | Lock screen |
| `Ctrl+Alt+T` | Open a new terminal window |
| `Alt+Tab` | Switch between open apps |
| `` Alt+` `` | Switch between windows of the same app |
| `Super+Left` / `Super+Right` | Snap window to left / right half of screen |
| `Super+Up` / `Super+Down` | Maximize / minimize window |
| `Ctrl+Alt+F2`...`F6` | Switch to another TTY (text console) |
| `Ctrl+Alt+F1` (or `F2`) | Switch back to the graphical desktop |
| `Print Screen` | Take a full-screen screenshot |
| `Shift+Print Screen` | Take a screenshot of a selected area |
| `Ctrl+Q` | Quit current application |

## Tips

- You don't need to memorize these on purpose — use them deliberately for a
  few days and they'll stick.
- If you forget one, that's what `Ctrl+Shift+P` (VS Code command palette) is
  for: type what you want to do in plain English and it'll show you the
  shortcut.
- Mac users: swap `Ctrl` for `Cmd` in most editor/OS shortcuts above (terminal
  shortcuts stay `Ctrl`).
